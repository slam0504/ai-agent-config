# 台灣慣用語詞條表(使用者校正批次)

書面中文(報告、文件、commit message、MR 描述、對話輸出)遵循台灣慣用語。
本表為 `preferences.md`「Taiwan-preferred wording」泛則的具體詞條,來自使用者
2026-07-03 的用語校正。

| 避免 | 使用 | 說明 |
|---|---|---|
| 根因 | 原因 | 使用者實際用語習慣 |
| 灰度(發布) | 分批上線 / canary release | 「灰度」為對岸用語,台灣不通用 |
| 上報 | 回報 / 開 issue 給上游 | 「上報」偏對岸公文語感 |
| 回滾 | rollback / 回退 | 工程溝通直接用原文最清楚 |
| (訊息 / 資料)落地 | 寫入 / 送達 | 「落地」保留給「方案落實」語境 |
| 體檢(repo 體檢) | 健檢 | 台灣說健康檢查 / 健檢 |
| ○○窗(停頓窗 / 觀察窗) | ○○期間 / window(原文) | 「窗」單字直譯生硬 |
| 錯位消費 | 從錯誤的 offset 消費 | 生造詞,直接描述 |
| 離組 | 離開 group | leave group 直譯生硬 |

**核心原則(使用者明示)**:台灣中文語境沒有合適對應詞時,直接用英文原文並
附註說明,不要生造中文譯名。

**Why**:共同語言降低溝通摩擦;生造譯名與對岸用語會讓正式文件觸發違和感,
需要使用者反覆校正。

**How to apply**:輸出任何書面中文前對照本表;遇到新的技術詞彙先判斷台灣
是否有慣用譯名,沒有就用原文加一句說明。使用者再校正新詞時,更新本表。
