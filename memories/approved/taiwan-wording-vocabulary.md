## 語感避免類

- 「動詞+爆」構詞(拉爆 / 打爆 / 捅爆 / 刷爆)— 對岸網路語感
- 帶政治梗的流行語(開好開滿 / 發大財 / 貨出得去)— 技術文件會觸發政治聯想
- 中性網路語(一坨 / 超猛 / 神扯 / 爆炸)— 閒聊可用,正式書面避免

**核心原則(使用者明示)**:台灣中文語境沒有合適對應詞時,直接用英文原文並
附註說明,不要生造中文譯名。

## 校對工作流

1. 若環境有 `zhtw-mcp` 之類的台灣化 lint 工具,先跑 lint 列 issue
2. 分四類:必改 / 建議改 / false positive(語境誤判,如「一次性 → 拋棄式」、
   「前綴 → 字首」、「通過[pass 意] → 透過」)/ 排版破壞(標點空格刪除、
   `-` → `~` 數字範圍、表格半形 `,` 改全形)
3. 必改 batch replace、邊緣按偏好、false positive + 排版類絕不動
4. 完成後使用者肉眼掃補抓字典盲區

全文詞彙替換前先 grep 既有用詞,對齊 dominant 版本,避免引入新詞造成不統一。
不確定某詞是否台灣常用時,主動標出讓使用者選、不要默默用下去。

**Why**:共同語言降低溝通摩擦;生造譯名與對岸用語會讓正式文件觸發違和感,
需要使用者反覆校正。

**How to apply**:輸出任何書面中文前對照本表;遇到新的技術詞彙先判斷台灣
是否有慣用譯名,沒有就用原文加一句說明。使用者再校正新詞時,更新本表。
